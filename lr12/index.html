Лабораторна робота №1

Рівень 4-6 балів

Завдання 1. Діалогове вікно → після "ОК" вивести "Hello, Прізвище Ім'я!"
Завдання 2. Діалогове вікно з "Ок"/"Відміна" → повідомлення, яку кнопку натиснуто
Завдання 3. Таблиця множення для числа (остання цифра номера у журналі)

Рівень 7-9 балів

Завдання 1. Перевірка парне/непарне число (номер у журналі), кольоровий абзац
Завдання 2. Пароль з перших 3 літер імені + номер у журналі * 2
Завдання 3. Три оцінки через prompt → середнє у блоці з id = номер у журналі
Завдання 4. Кількість студентів → прізвища та імена по черзі

Рівень 10-12 балів

Завдання 1. Список (ul) з літер імені. Наведення миші → alert з літерою
    Завдання 2. Введення прізвищ та імен, поки не натиснуть "Відміна"
    Завдання 3. Кнопка "Показати блоки" — блоки з літер прізвища, hover → alert, повторний клік очищає
